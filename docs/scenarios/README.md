# Eval scenarios: DRAFT LABELS

**DRAFT LABELS.** The build agent wrote these scripts and labels on Malcolm's default for Q1 (`QUESTIONS.md`). Neither founder has confirmed them. Any score measured against them is provisional.

Each scenario is a two-speaker script, spoken by two different macOS voices during a real two-panel call.

- `A:` / `B:` start each spoken line.
- `[c1]` marks a line containing labeled claim `c1`. The tag is never spoken.
- Lines with no tag are small talk, opinions or personal anecdotes. A claim detected on one of those lines is a false positive.

Each label gives the claim, the expected verdict (`supported` or `disputed`), a source URL opened on 2026-10-30, how it was opened, and a verbatim passage from that page. The source passes the allowlist from `QUESTIONS.md` Q5.

These files are frozen once committed. They are never edited to raise a score.
